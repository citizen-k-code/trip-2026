# Nepal & Bhutan — October 2026

A three-page trip site: day-by-day itinerary, practical arrangements, and tips & customs
for a 24-day journey through the Kathmandu Valley, Bhutan, and the Mardi Himal trek
above Pokhara.

| Page | What's on it |
|---|---|
| `index.html` | Day-by-day itinerary, 25 Sep – 18 Oct, with an altitude profile |
| `practical.html` | Bookings, permits, transfers, money, connectivity, luggage, health |
| `tips.html` | Etiquette, food, and what not to miss in each country |

Static HTML with one stylesheet — no build step, no dependencies.

**Note:** this is the public copy. Booking references, PINs and visa numbers have been
removed; they live only in the private working copy.
